# 고정 물체 상자 운반 검증 계획

사용자가 다음 동작 검증 진행을 요청했다. 기존 `contact_grasp_probe.py`에 상자 운반 시나리오를 추가하고, 기존 집기 시나리오를 보존한다.

명세: ../specs/2026-10-04-shape-sort-design.md

- [x] 파란 상자와 초록 상자를 바닥·네 벽의 실제 충돌 형상으로 배치한다.
- [x] 집기·들림 검증 후 상자 벽보다 높은 위치로 이동하고, 파란 상자로 운반·내려놓기·개방·후퇴한다.
- [x] 물체 전체 AABB가 상자 내부에 있고 바닥에 접촉하며 낮은 속도로 0.5초 유지되는지 확인한다. 이 실험의 지정 목적지는 파란 상자다.
- [x] 운반 중 개방 낙하와 초록 상자로 잘못 옮기는 대조 실험으로 낙하/지정 목적지 실패를 구분한다.
- [x] 동일 조건 정상 운반10회, 각 대조군1회, GUI 정상1회 실행한다.
- [x] 실제 설정·위치·판정·실행 명령을 기존 안내와 진행/실험 기록에 남긴다.

실제 결과: run_id `20261004T183452_711685`, 정상 운반 10/10·낙하 0/10, 대조군 2개 예상 판정 통과, unittest 11개 통과. GUI에서 사용자가 파란 상자로 옮기는 모습을 확인했다. 새 검증 3개의 초기 실패 후 구현해 통과를 확인했다. 기존 집기 시나리오는 보존했다. 고정 조건 실험이며 일반 장애물 회피·카메라·CNN·ROS2 통합은 아직 없다.

정보 경계: 고정 좌표 oracle 실험. 카메라/CNN의 분류·좌표 추정은 아직 연결하지 않는다. 강제 부착·실행 중 pose reset을 사용하지 않는다. 두 상자는 후속 분류의 장면 후보이며 카메라 시야와 작업 범위를 확인한 후 배치를 조정할 수 있다.
