# 원기둥 카메라 집기·운반 검증 계획

사용자가 원기둥 단계 진행을 지시했다. 기존 두 실행 파일과 두 테스트 파일을 확장하며 새 코드 파일·의존성을 추가하지 않는다.

명세: ../specs/2026-10-04-shape-sort-design.md

- [x] 원기둥 렌더링의 중심·지름·높이와 실제 운반 테스트를 먼저 작성하고 미구현 실패를 확인한다.
- [x] 공통 영상 처리 뒤 cuboid_geometry()/cylinder_geometry()로 윗면 기하를 구한다. 원기둥은 X·Y 양 끝의 중앙과 평균 지름, 고정 yaw를 쓴다.
- [x] grasp_plan()으로 공통 손끝 목표를 만든다. 현재 두 도형 모두 상면 아래15mm·열림 여유15mm·기존 힘을 사용한다.
- [x] --object-shape cylinder와 지름·높이 옵션으로 원기둥 초기 배치를 구성한다. 도형 종류는 수동 입력이며 CNN 예측이 아니다. 실제 크기·좌표는 인식/계획에 전달하지 않는다.
- [x] 기존 테스트 회귀, 원기둥 정상10회·운반낙하/오도착/빈 관측 대조, 위치·크기 변경과 GUI를 확인한다.
- [x] 이미지·설정·오차·결과를 저장하고 의사결정에 계산과 구현 함수·한계를 쉽게 설명한다.

판정은 실제 접촉·물체 상태를 사용한다. 초기 배치 이후 강제 부착·순간이동 없이 진행하며, 재시도·CNN·ROS2는 이번 범위에서 구현하지 않는다. 기존 변경 보존, commit/push 없음.

결과: 테스트18개, 기본10/10 및세변경사례·실패대조·GUI 사용자확인. 추가 발견/수정: 작은 원기둥 놓기 중 손바닥-상자벽 충돌, 최소놓기높이 floor_top+25mm 도입과회귀검증. 최초실패·최종성공로그 모두보존.
