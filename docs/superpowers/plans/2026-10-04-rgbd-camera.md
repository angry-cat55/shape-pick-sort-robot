# RGB-D 카메라 좌표 기반 접촉 집기 검증 계획

목적: 합의한 대각선 위 카메라로 좌표를 추정하고 기존 접촉 집기·상자 운반을 연결한다.

## 승인된 범위
- 고정 RGB-D 카메라, 빈 테이블 깊이 차이, 월드 좌표 역투영을 사용한다.
- 평평한 직육면체 하나의 상면으로 중심·높이·폭·yaw를 추정한다. CNN·원기둥·재시도는 다음 단계다.
- 실제 pose/body ID segmentation은 인식 입력에서 제외하고 오차·집기 검증에만 사용한다.
- 기존 모터 제어·접촉 검증을 재사용한다. 학습용 이미지 경로와 카메라 설정을 저장한다.

## 작업과 검증
- [x] `tests/test_rgbd_camera.py`: 빈 영상의 거부와 렌더링 물체 좌표 오차를 먼저 검사한다.
- [x] `scripts/rgbd_camera.py`: 촬영·역투영·물체 영역·상면 기하·RGB crop을 구현한다.
- [x] 기존 probe에 camera 입력 모드를 추가한다. 추정 실패는 로봇 이동 전에 중단한다.
- [x] 기존 테스트와 카메라 기반 운반·빈 장면 대조를 실행한다.
- [x] 세 카메라 각도에서 관측을 비교하고, 선택 설정의 반복 운반과 위치 변화를 검증한다.
- [x] RGB·깊이·마스크·추정/실제 오차·결과를 저장하고 안내·진행 기록을 갱신한다.

사용자의 다음 단계 진행 지시에 따라 현재 세션에서 직접 구현한다. 기존 작업을 보존하며 commit/push는 수행하지 않는다.
