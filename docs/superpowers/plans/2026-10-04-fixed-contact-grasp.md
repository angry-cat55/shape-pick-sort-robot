## 실행과 검증

- [x] 모델에서 관절/link 이름을 조회하고 손끝 기준 `panda_grasptarget`의 정적 IK 좌표 관계를 확인한다. 정적 joint reset 검사는 파지 성공 실험과 구분한다.
- [x] 높이 0.30m의 고정 상판과 Panda 기반, 40×30×40mm/0.05kg 물체 하나를 배치한다.
- [x] 초기 배치 후 pose reset·강제 부착 없이 IK→관절 모터 명령으로 접근/내려가기/닫기/10cm 들기/1초 유지/내려놓기/개방을 실행한다.
- [x] IK 관절 한계·손끝 목표 오차를 확인한다. 파지 전에 팔/테이블 충돌이나 도달 실패가 있으면 실패로 기록한다.
- [x] 실제 물체 최저 높이가 상판보다 5cm 이상인 상태를 1초 유지하는지 검사한다. 받침대·테이블·다른 로봇 링크 지지를 성공으로 오인하지 않고, 손가락 접촉과 상대 위치 변화를 보조 증거로 기록한다.
- [x] 고정 설정 정상 10회에서 lift/유지/내려놓기 10회 통과를 목표로 한다. 반복은 같은 설정의 재현 검사이며 다양한 조건의 성공률이 아니다.
- [x] 빗나간 목표는 lift=False, 들어 올린 뒤 개방은 실제 낙하 감지, 별도 받침대가 물체를 지지하는 높은 위치는 lift=False로 확인한다.
- [x] GUI 정상 집기 1회를 실행하고 사용자의 화면 관찰을 요청한다.
- [x] 실행 명령·설정·실패와 수정 근거를 기록하고 이번 검증의 한계를 설명한다.
