## 데이터 수집 중 확인한 집기 보완 사항

2026-10-05, 다양한 크기의 CNN 데이터 수집 단계에서 확인했다. 아래는 사용자가 새 기능으로 채택한 목록이 아니라, 이후 모델 연결 때 필요한 검증 메모다.

- 현재 `estimate_many()`의 기본 크기 전용 가림 검사를 다양한 크기에서도 쓸 수 있게 보완해야 한다. 생성 정답 크기로 검사를 대신하지 않는다.
- 6.4×6.4cm 정사각형 윗면은 긴 방향이 모호해서 현재 PCA 폭 추정이 범위를 벗어나 보류됐다. 정사각형 방향·폭 계산과 실제 파지를 별도로 검증해야 한다.
- 높이7cm는 일부 단일 물체에서 뒤쪽 상자 운반에 성공했지만, 높이·가로 폭·위치·Yaw 조합 전체의 성공은 미검증이다.
